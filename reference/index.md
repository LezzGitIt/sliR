# Package index

## All functions

- [`build_cov_mat()`](https://LezzGitIt.github.io/sliR/reference/build_cov_mat.md)

- [`build_group_cor_tbl()`](https://LezzGitIt.github.io/sliR/reference/build_group_cor_tbl.md)

- [`build_sli_slopes_hierarchical()`](https://LezzGitIt.github.io/sliR/reference/build_sli_slopes_hierarchical.md)

- [`build_sli_slopes_tbl()`](https://LezzGitIt.github.io/sliR/reference/build_sli_slopes_tbl.md)
  : Per-group SMA allometric slopes

  : Standardized Length Index (SLI)

  : Resolve an allometry from any sufficient subset of its parameters

- [`implied_gradient_effect()`](https://LezzGitIt.github.io/sliR/reference/implied_gradient_effect.md)
  : Resolve the ground-truth effect of a gradient on relative appendage

- [`sim_allometric()`](https://LezzGitIt.github.io/sliR/reference/sim_allometric.md)
  : Simulate log-normal morphology, optionally along an environmental
